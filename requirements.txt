# Accounts Payable & Duplicate Payment Detection

A major process-mining project for analyzing accounts payable workflows, detecting duplicate payments, and identifying workflow deviations using synthetic invoice event logs.

## Project links

1. Project Program + Execution + Result: https://github.com/Rithish-255/accounts-payable-fraud-detection
2. Academic Implementation Download: https://github.com/Rithish-255/accounts-payable-fraud-detection/blob/main/docs/ACADEMIC_IMPLEMENTATION.md

## Objective

This project simulates an enterprise invoice-to-pay process and applies process-mining concepts to detect:

- duplicate payments
- rogue or unauthorized payments
- skipped approvals
- looping / repeated invoice activities
- abnormal approval-to-payment delays

## Core Concepts Used

- Case conformance checks
- PU_COUNT
- Activity lag analysis
- Process loops and rework detection
- Fraud-risk detection in AP

## Real-World Context

This mirrors enterprise accounts payable problems often found in large organizations, where duplicate invoice flows and approval bypass lead to significant financial losses.

## Project Structure

- `src/ap_process_mining.py` — core logic and metrics
- `src/main.py` — execution entry point
- `outputs/duplicate_payment_summary.json` — JSON results
- `outputs/ap_process_report.md` — summary report
- `docs/ACADEMIC_IMPLEMENTATION.md` — academic write-up
